# Security Policy

## Supported Versions

Only the latest release and the current active branch receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

We take the security of **Ether-MOSH** seriously. If you believe you have found a security vulnerability, please do not report it through public GitHub issues or discussions.

### How to Report

1. **GitHub Security Advisory (Preferred):** Go to the [Security tab](https://github.com/Mlswchr75/Ether-MOSH/security) of this repository and click **"Report a vulnerability"** to submit a private report.
2. **Direct Contact:** If private reporting is unavailable, reach out directly via repository maintainer contact details with the subject line `[SECURITY] Ether-MOSH Vulnerability Report`.

### What to Include in Your Report

* A clear description of the vulnerability and its potential impact.
* Step-by-step instructions or a minimal Proof of Concept (PoC) to reproduce the issue.
* Any relevant details regarding your environment (browser, OS, device).
* Suggested mitigations or fixes, if you have any.

### Response & Disclosure Process

* **Acknowledgment:** You will receive an initial response within **48 hours** confirming receipt.
* **Assessment:** The report will be investigated and triaged to determine severity and scope.
* **Fix & Release:** A patch will be developed and deployed in a new release as soon as possible.
* **Coordinated Disclosure:** We kindly ask that you keep the details confidential until a fix has been published and users have had reasonable time to update.
