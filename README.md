# Ether-MOSH

An interactive, high-performance visual effects engine and canvas instrument designed for real-time video manipulation, dynamic glitch art, dynamic intensity scaling, and temporal feedback suites.

---

## 🌟 Features

* **Real-Time Visual Processing:** Dynamic canvas rendering and post-processing FX chains.
* **Dimensional Engine & Intensity Scaling:** Modular intensity controls, temporal feedback loops, and HDR color scaling.
* **Multi-Input Support:** Live camera feed integration, file upload suite, and canvas composition tools.
* **User Authentication & Cloud Storage:** Powered by Supabase for user profiles, preset saving, and media management.
* **Modern UI Architecture:** Responsive layout with dark-mode optimized canvas interfaces.

---

## 🛠️ Tech Stack

* **Frontend:** [React](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Vite](https://vitejs.dev/)
* **Rendering & FX:** WebGL, HTML5 Canvas API
* **Backend & Auth:** [Supabase](https://supabase.com/) (Google/Apple OAuth)
* **Deployment & CI/CD:** [Netlify](https://www.netlify.com/)
