# News + Updates design system

The accepted direction uses Ether-MOSH's near-black field, bone-white type, signal magenta, and acid yellow-green. It avoids rounded SaaS cards in favor of open editorial bands, hard rules, oversized condensed headlines, numbered data rows, and image-led reporting.

- `news-index-concept.png`: 1536×1024 index concept.
- `news-article-concept.png`: 864×1821 long-form article concept.
- Production assets use original 16:9 generated editorial art at 1672×941.
- Mobile collapses grids to a single reading flow while preserving the masthead, answer box, downloads, FAQs, and sources.
