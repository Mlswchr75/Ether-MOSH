# Ether-MOSH Posterize field card

## Quick recipe

- Category: Color
- Levels: 5
- Bias: 0.50
- Source: clear light-dark structure with deliberate gradients
- Optional stack: Duotone before Posterize; low Film Grain after it

## Control map

| Control | Range | What it changes |
| --- | ---: | --- |
| Levels | 2–16 | Size of the per-channel RGB quantization steps |
| Bias | 0–1 | Shifts tone values before they are quantized |

## Production checklist

1. Start at 5 Levels and 0.50 Bias.
2. Use 2–4 Levels for blunt flat regions and 8–12 for quieter banding.
3. Move Bias below 0.50 for darker placement or above 0.50 for lighter placement.
4. Inspect faces, gradients, labels, and fine edges at 100%.
5. Proof print work at final physical size and venue work on the actual display.
6. Treat the RGB export as artwork, not an automatic spot-color separation.

## Accessibility note

If the effected image contains meaningful text or diagram labels, verify final light-dark contrast and preserve an accessible equivalent. Saturated color does not guarantee readability.
