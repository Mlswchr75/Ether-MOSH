# Ether-MOSH Field Card: Pixel Sort

## Fast recipe

- Category: Data Corruption
- Amount: 0.25–0.60
- Threshold: 0.35–0.65
- Best sources: hard light, silhouettes, architecture, type, night lights
- Useful stack: Pixel Sort → RGB Shift → Film Grain

## Production checklist

- Judge Threshold on the subject, not the background.
- Animate one control slowly for loops and projection.
- For print, export at final aspect ratio, inspect at 100%, and use the 300 DPI print-ready export.
- For repeats, test a 3×3 tile before production.
- Pixel Sort is raster. Trace only intentional silhouettes when a vector deliverable is required.
