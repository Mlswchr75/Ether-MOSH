# Ether-MOSH Field Card: Halftone

## Fast recipe

- Category: Color
- Amount: 0.40–0.78
- Dot Size: choose for the final viewing distance
- Useful stack: Duotone → Halftone → Photocopy

## Production checklist

- Fine dots serve editorial detail; coarse dots survive posters, thumbnails, textiles, projection, and LED walls.
- Proof at final physical size. A screen preview is not a press proof.
- Avoid claiming the live effect is a production CMYK separation.
- For motion, animate Dot Size gently and monitor flicker/accessibility.
