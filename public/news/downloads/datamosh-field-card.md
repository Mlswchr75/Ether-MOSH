# Ether-MOSH Field Card: Datamosh

## Fast recipe

- Category: Data Corruption
- Amount: 0.30–0.68
- Block Size: 0.015–0.040
- Best sources: dancing, pans, hands, traffic, subjects crossing frame
- Useful stack: Datamosh → RGB Shift → Film Grain

## Production checklist

- Use one clear movement so displaced blocks have readable direction.
- Raise Amount before enlarging Block Size.
- Record through a movement or scene change instead of holding one damaged frame forever.
- For print, choose a frame whose block edges support the composition and export at 300 DPI.
- Ether-MOSH performs a live shader interpretation; it does not corrupt the source file.
